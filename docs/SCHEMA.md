# Database schema

Postgres 16 with `pg_trgm`. Do not edit this file — propose changes in your
response and wait.

## Tables

**orders** — one row per published order document
`id, order_date, subject_raw, case_number, bench, pdf_url, pdf_sha256,
file_size_bytes, remarks_raw, outcome, page_count, is_scanned,
processing_status, retrieved_at, source_listing_page`

**order_pages** — `id, order_id, page_number, text`

**cases** — orders grouped into one insolvency proceeding
`id, canonical_case_number, corporate_debtor_name, bench, first_order_date,
latest_order_date, current_outcome`

**case_aliases** — `id, case_id, alias_text, alias_type`

**link_review_queue** — fuzzy candidates awaiting human confirmation
`id, order_id, candidate_case_id, similarity, status, reviewed_at`

**extracted_fields** — `id, order_id, case_id, field_name, value_text,
value_numeric, value_date, unit, verified, extraction_method, model_name,
extracted_at`

**evidence** — `id, extracted_field_id, order_id, page_number, quote,
char_start, char_end`

**gold_labels** — `id, order_id, field_name, expected_value, labelled_by,
labelled_at`

**ingestion_runs** — `id, started_at, finished_at, pages_scanned, orders_found,
orders_new, orders_processed, orders_failed, llm_calls, watermark, notes`

## Enums

`outcome`: admitted | cirp_ongoing | resolution_approved | liquidation |
dissolved | withdrawn | unclassified

`processing_status`: discovered | downloaded | text_extracted |
scanned_skipped | extracted | failed

`creditor_type`: financial | operational | corporate_applicant

## Indexes

`orders(order_date)`, `orders(outcome)`, `orders(bench)`,
`orders(pdf_url)` unique, `extracted_fields(case_id, field_name)`,
`cases(corporate_debtor_name)` gin_trgm_ops

## Rules

- Money in `Decimal(20,2)`, never float
- All timestamps `TIMESTAMPTZ`, stored UTC
- `pdf_url` unique — it is the deduplication key alongside `pdf_sha256`
- `evidence` rows are never updated, only inserted or deleted with their parent
- Never edit an applied Alembic migration; add a new revision
